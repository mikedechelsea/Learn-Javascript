Practice Project Ideas

Building small, real things is the fastest way to make a concept stick. Here are four beginner-friendly projects that use nothing but HTML, CSS, and the JavaScript concepts from this course.

✅ To-Do List with Local Storage

Add, check off, and delete tasks using the DOM. Save the list to Local Storage so it's still there the next time the page loads — a perfect combo of arrays, objects, and browser storage.

🧠 Multiple-Choice Quiz App

Store questions as an array of objects, loop through them, track the score with variables, and use conditionals to reveal whether each answer was right.

🧮 Tip or BMI Calculator

Read values from form inputs, run the math in a function, and write the result back into the DOM. A small project that ties together functions, operators, and events.

✊ Rock, Paper, Scissors

Use click events, an array of possible moves, Math.random() to pick the computer's move, and conditional logic to decide the winner.
